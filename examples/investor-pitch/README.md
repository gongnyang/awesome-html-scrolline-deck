# 모아: 동네 가게의 빈 시간을 채우다

초기 투자 검토용 가상 사업 제안입니다. 브랜드, 점포 수, 시장 규모, 파일럿 목표와 사례는 실제 운영 성과나 조사 결과가 아닙니다.

## 장면 흐름

| # | 장면 | 발표에서 하는 일 | 자료 상태 |
|---:|---|---|---|
| 1 | `01-hero` | 가게의 빈 좌석과 가까운 고객의 저녁 예약을 연결한다. | 가상 사업 시나리오 |
| 2 | `02-problem` | 18:42 빈자리 발견부터 19:11 예약 확정까지 가상 사례를 따라간다. | 가상 사례 · 실제 거래 아님 |
| 3 | `03-market` | 가상 후보 8,000곳 중 첫 검토 대상 2,400곳(30%)을 보여준다. | 가상 시장 가정 · 실제 조사값 아님 |
| 4 | `04-product` | 가게의 당일 좌석 공개부터 고객 예약 확정까지 제품 흐름을 설명한다. | 가상 제품 흐름 |
| 5 | `05-model` | 점포 등록, 고객 발견, 예약 완료를 잇고 12% 수수료 가정을 제시한다. | 가상 수익모델 · 실제 수익 아님 |
| 6 | `06-traction` | 파일럿에서 확인할 네 지표와 분모·기간을 정의한다. | 가상 파일럿 목표 · 실제 성과 아님 |
| 7 | `07-economics` | 세 고객 유입 가설을 같은 측정 기준으로 비교한다. | 설계 목표와 가설 · 관측값 없음 |
| 8 | `08-competition` | 유지·조정·중단 조건으로 파일럿 판단 규칙을 제안한다. | 가상 의사결정 예시 · 실제 성과 아님 |
| 9 | `09-ask` | 점포 확장 전 8주 재방문 가설을 단계별로 검증한다. | 가상 일정과 목표 |
| 10 | `10-close` | 파일럿 범위·측정 지표·중단 조건에 관한 다음 협의를 요청한다. | 가상 제안 |

각 장면에는 발표자 노트가 포함되어 있습니다. 실행 중 `N` 키를 누르면 현재 장면의 노트를 열 수 있습니다. 화살표 키나 스페이스로 장면을 이동하고, `F`로 전체 화면을 전환합니다.

```sh
cd examples/investor-pitch
pnpm install
pnpm run dev
```
