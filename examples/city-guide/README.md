# 서울, 해질녘 한 바퀴

서울 저녁 산책을 제안하는 8장면 웹덱입니다. 시간·이동 순서·이미지는 현장 안내가 아닌 설계 예시이며, 실제 출발 전 교통과 시설 운영 정보를 확인해야 합니다. 장소 사진은 AI 콘셉트 이미지로 표시합니다.

## 장면 흐름

| # | scene id | 장면 템플릿 | 실제 제목과 발표 역할 |
|---:|---|---|---|
| 1 | `01-hero` | `frame-scrub-hero` | **도시는 천천히 걸을 때 더 많이 보인다** — 100프레임 저녁 풍경을 스크롤로 펼치는 시네마틱 도입입니다. |
| 2 | `02-route` | `map-route` | **길이 바뀔 때마다 저녁의 빛도 바뀐다** — 여의나루 → 서촌 → 광장시장 → 청계천의 제안 순서와 장소별 시각을 설명합니다. |
| 3 | `03-stops` | `horizontal-gallery` | **한 경로 안에서 저녁의 색이 바뀐다** — 강변·한옥 골목·시장·물길 사진과 장소명을 하나씩 바꿔 보여 줍니다. |
| 4 | `05-pause` | `parallax-video` | **도시는 잠깐 멈출 때 더 선명하다** — 고정된 물길 장면에 머물며 발표 속도를 낮추는 비핀 전환입니다. |
| 5 | `06-route-proof` | `agenda-path` | **좋은 길은 바꿀 수 있다** — 날씨·피로·귀가 조건에 맞춰 경로를 조정하는 행동을 제안합니다. |
| 6 | `07-choices` | `option-matrix` | **같은 저녁, 세 가지 길이** — 전체 경로·시장 중심·강변 중심 구성을 수치 없이 질적으로 비교합니다. |
| 7 | `09-packing` | `step-flow` | **가볍게 준비하고, 편하게 돌아옵니다** — 신발·물·귀가 경로를 실제 출발 행동 순서로 묶습니다. |
| 8 | `10-close` | `closing-qr` | **끝까지 걷지 않아도 충분한 산책** — 완주 대신 일정에 맞는 한 구간을 선택하도록 마무리합니다. |

각 장면에는 발표자 노트가 포함됩니다. 실행 중 `N` 키로 노트를 열고, 화살표 키나 스페이스로 이동하며, `F`로 전체 화면을 전환합니다.

## 실행

```sh
cd examples/city-guide
pnpm install
pnpm run dev
```

## 근거와 한계

이 덱은 저녁 산책 구성의 가상 제안입니다. 표시된 시각은 실제 교통편이나 체류시간 측정값이 아니며, 걷기 거리·운행 여부·운영시간·야간 안전을 보증하지 않습니다. 위치와 동선을 실제 안내로 이용하기 전에 공식 지도와 운영기관 정보를 확인해야 합니다.
