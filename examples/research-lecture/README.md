# 도시의 그늘은 누구에게 충분한가

보행자 열 노출과 가로수 분포를 읽는 수업용 합성 사례입니다. 실제 대학로 조사나 연구 결과가 아닙니다.

## 장면 흐름

| # | 장면 | 발표에서 하는 일 | 자료 상태 |
|---:|---|---|---|
| 1 | `01-hero` | 같은 거리에서도 시간과 가로수에 따라 그늘이 달라지는 질문을 연다. | 수업용 합성 사례 |
| 2 | `02-question` | 그늘 위치가 보행·체류와 어떻게 겹치는지 현장 질문을 던진다. | 수업용 합성 사례 |
| 3 | `03-method` | 12개 블록 × 블록당 20구간을 표본으로 삼고, 시간별 그늘과 사람 관찰을 분리한다. | 합성 측정 설계 · 실제 관측 아님 |
| 4 | `06-findings` | 같은 0–100% 축에서 09시 46%, 14시 28%와 −18%p 차이를 비교한다. | 수업용 합성값 · 분모는 표본 보행 구간 |
| 5 | `07-annotation` | 새 15시 값 31%는 14시보다 3%p 회복했지만 09시보다 15%p 낮다. | 수업용 합성값 · 같은 분모 |
| 6 | `08-limits` | 그늘 면적만으로 기온·체감·체류나 건강 영향을 알 수 없음을 구분한다. | 합성 결과와 자료 한계 |
| 7 | `10-close` | 다음 현장 측정 질문을 정리하고 토론으로 닫는다. | 합성 결과 · 실제 관측 아님 |

각 장면에는 발표자 노트가 포함되어 있습니다. 실행 중 `N` 키를 누르면 현재 장면의 노트를 열 수 있습니다. 화살표 키나 스페이스로 장면을 이동하고, `F`로 전체 화면을 전환합니다.

## 실행

```sh
cd examples/research-lecture
pnpm install
pnpm run dev
```

모든 수치와 지도는 강의 설명을 위한 합성 자료이며 실제 관측 결과나 논문 인용이 아닙니다.
