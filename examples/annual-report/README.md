## 장면 흐름

| # | scene id | 장면 템플릿 | 발표에서 하는 일 |
|---:|---|---|---|
| 1 | `01-hero` | `frame-scrub-hero` | 매출 규모보다 수익의 질을 보겠다는 핵심 판단을 연다 |
| 2 | `03-trend` | `annotated-chart` | 312→433억 원의 분기 매출과 마지막 분기 증가율 둔화를 함께 읽는다 |
| 3 | `04-drivers` | `before-after` | 반복 매출 비중 41%와 54%를 같은 기준선에서 비교한다 |
| 4 | `08-risks` | `document-proof` | 반품률과 신규 고객 획득비의 미해결 원인을 밝힌다 |
| 5 | `09-next` | `agenda-path` | 고객 유지·물류·재고의 세 운영 기준을 제시한다 |
| 6 | `10-close` | `agenda-path` | 투자 순위보다 측정 책임자·기준선·재검토일 합의를 요청한다 |

각 장면에는 발표자 노트가 포함되어 있습니다. 실행 중 `N` 키를 누르면 현재 장면의 노트를 열 수 있습니다. 화살표 키나 스페이스로 장면을 이동하고, `F`로 전체 화면을 전환합니다.

## 실행

저장소 루트에서 다음 명령을 실행합니다.

```sh
cd examples/annual-report
npm ci
npm run dev
```

## 발표 자료 안내

밀물의 브랜드, 분기 매출, 수익 지표와 운영 과제는 모두 발표 설계를 보여 주기 위한 **가상 경영 시나리오**입니다. 실재 회사의 성과로 인용하지 마세요. 공개 전에는 `node scripts/cli.mjs verify examples/annual-report --strict --build`를 저장소 루트에서 실행하고 발표 화면·모바일·모션 감소 캡처를 확인합니다.
