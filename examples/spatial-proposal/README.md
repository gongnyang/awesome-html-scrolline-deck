# 온기 도서관 리모델링·증축 제안

기존 동네 공공건물 1층에 도서관 기능과 2층 증축을 더하는 가상 클라이언트 제안입니다. 목표 면적은 기존 320㎡와 증축 320㎡를 합한 640㎡입니다. 실측·구조 검토·인허가 전의 계획 예시이며 렌더 이미지는 시공 결과가 아닙니다.

## 장면 흐름

| # | 장면 | 발표에서 하는 일 | 자료 상태 |
|---:|---|---|---|
| 1 | `01-hero` | 단층 공공건물을 640㎡ 도서관으로 바꾸는 범위를 소개한다. | 가상 프로젝트 브리프 |
| 2 | `02-before` | 기존 건물과 2층 증축 후의 외관·범위를 비교한다. | 개념 설계 |
| 3 | `03-thesis` | 열린 1층, 조용한 2층, 두 층을 잇는 계단 원칙을 제안한다. | 개념 설계 |
| 4 | `04-gallery` | 여섯 프로그램이 층별 이용 목적에 맞는지 검토한다. | 가상 공간 계획 |
| 5 | `05-materials` | 기존 미장 벽 보존을 우선하고 목재 난간·유약 타일·천장 루버의 적용 위치와 검토 이유를 비교한다. | 설계 예시 · 유지관리 조건은 협의 대상 |
| 6 | `06-journey` | 방문자가 입구에서 두 층으로 이동하는 세 상태를 따라간다. | 개념 동선 |
| 7 | `07-seating` | 모임 좌석과 집중 좌석의 층별 운영 구상을 검토한다. | 가상 운영 구상 |
| 8 | `08-experience` | 낮과 저녁에 두 층이 공공 거실로 쓰이는 모습을 제시한다. | 공간 사용 시나리오 |
| 9 | `09-accessibility` | 1층 진입과 2층 접근성의 설계 확인 항목을 합의한다. | 설계 검토 항목 |
| 10 | `10-operations` | 기본 설계부터 운영 인수까지의 가상 업무 범위를 확인한다. | 가상 일정 · 실측·구조 검토·인허가 후 확정 |
| 11 | `11-next` | 현장 실측, 구조 검토, 예산 합의를 다음 단계로 정한다. | 가상 프로젝트 브리프 |

실행 중 `N` 키로 발표자 노트를 보고 화살표 키나 스페이스로 장면을 이동합니다.

```sh
cd examples/spatial-proposal
pnpm install
pnpm run dev
```
