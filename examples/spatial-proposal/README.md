# 온기 도서관 리모델링·증축 제안

기존 동네 공공건물 1층에 도서관 기능과 2층 증축을 더하는 가상 클라이언트 피치. 목표 면적은 기존 320㎡ + 증축 320㎡, 합계 640㎡입니다. 구조 검토·실측·인허가 전의 계획 예시이며 모든 렌더링은 동일 현장의 실제 사진이나 시공 결과가 아닙니다.

| # | 장면 | 발표에서 하는 일 |
|---:|---|---|
| 1 | `01-hero` · `frame-scrub-hero` | 1층 주민센터에 2층을 더해, 동네의 도서관으로 |
| 2 | `02-before` · `before-after` | 1층 주민센터에 2층을 증축합니다 |
| 3 | `03-thesis` · `tilt-card` | 열린 1층 · 조용한 2층 · 연결되는 계단 |
| 4 | `04-gallery` · `horizontal-gallery` | 두 층, 여섯 가지 쓰임 |
| 5 | `05-materials` · `paper-assembly` | 오래 쓰고 쉽게 고치는 마감 |
| 6 | `06-journey` · `horizontal-gallery` | 들어오고, 살펴보고, 층을 잇는 여정 |
| 7 | `07-seating` · `before-after` | 모임은 1층, 집중은 2층에 |
| 8 | `08-experience` · `parallax-video` | 낮에는 공부방, 저녁에는 동네의 거실 |
| 9 | `09-accessibility` · `before-after` | 문턱 없는 입구와 층간 이동을 설계합니다 |
| 10 | `10-operations` · `document-proof` | 90일 기본설계·협의 계획 |
| 11 | `11-next` · `parallax-video` | 현장 확인 → 프로그램 합의 → 기본 설계 |

실행 중 `N` 키로 발표자 노트를 보고 화살표 키나 스페이스로 장면을 이동합니다.

```sh
cd examples/spatial-proposal
pnpm install
pnpm run dev
```
