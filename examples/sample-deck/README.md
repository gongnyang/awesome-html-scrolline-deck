# 한 장씩 넘기지 않는 발표

스크롤에 맞춰 장면이 바뀌는 발표 설계 강의 예시입니다. 현재 덱은 **9장**이며, 질문부터 한 장면 설계와 검수까지 실제 발표 흐름으로 구성했습니다.

## 장면 흐름

| # | 장면 | 화면 관계 | 발표에서 하는 일 |
|---:|---|---|---|
| 1 | `01-hero` | `frame-scrub-hero` | 스크롤로 생각의 변화 순간을 보여 주는 발표 개념을 소개합니다. |
| 2 | `02-question` | `question-reveal` | 청중이 최근 본 발표 장면을 3초간 떠올리게 합니다. |
| 3 | `03-claim` | `sequence-cards` | 수업용 가상 예약 사례에서 빈자리 발견이 선택과 예약 확정의 출발점임을 보여 줍니다. |
| 4 | `05-evidence` | `presenter-hold` | 발표자가 설명하는 동안 주장과 근거를 함께 읽을 수 있는 정지 화면을 설명합니다. |
| 5 | `06-flow` | `state-change-demo` | 같은 빈자리의 상태가 발견, 조건 확인, 예약 완료로 바뀌는 가상 시연입니다. |
| 6 | `07-templates` | `horizontal-gallery` | 주장·근거·출처를 함께 읽을 수 있는 원본 발표 화면과 선택 이유를 제시합니다. |
| 7 | `08-demo` | `three-state-sequence` | 같은 화분 단풍나무의 잎이 나기 전, 자라는 중, 무성해진 뒤를 보여 주는 콘셉트 장면입니다. |
| 8 | `09-checklist` | `option-matrix` | 화면 읽기, 브라우저 검증, 발표 리허설에서 확인할 기준을 정리합니다. |
| 9 | `10-close` | `kinetic-titles` | 다음 발표에서 주장 하나와 근거 하나를 함께 배치하도록 권합니다. |

장면 번호는 현재 데이터의 순서를 따릅니다. `04-agenda` 장면은 중복 흐름을 제거하며 덱에서 빠졌습니다.

## 사례와 자료 안내

예약 화면은 수업용 가상 시나리오이며 실제 서비스나 고객 데이터가 아닙니다. 단풍나무 이미지는 실제 표본이나 관측 기록이 아닌 콘셉트 이미지입니다. 발표 동작과 템플릿 예시에도 실측 데이터는 없습니다.

## 실행

저장소 루트에서 다음 명령을 실행합니다.

```sh
cd examples/sample-deck
npm ci
npm run dev
```

정적 빌드는 `npm run build`, 빌드 결과 미리보기는 `npm run preview`입니다.

## 조작과 접근성

화살표 키나 스페이스로 장면을 이동하고 `F` 키로 전체 화면을 전환합니다. `N` 키를 누르면 현재 장면의 발표자 노트를 열 수 있습니다. 모션 감소 환경에서도 장면의 핵심 주장과 안내가 완성된 정지 화면으로 제공됩니다.
