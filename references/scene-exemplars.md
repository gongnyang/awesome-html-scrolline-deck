# 완성 장면에서 배우는 선택 기준

`templates/scenes/`는 동작과 입력 계약을 제공한다. 아래 장면은 그 동작에 실제 주장·근거·이미지 방향·발표 정지 화면·다음 장면 연결을 부여한 구현 사례다. **주제나 외형을 복제하지 말고, 정보 관계와 발표 행위를 가져온다.** 엄격한 브라우저 검사를 통과한 예시라도 새로운 내용에 적용한 결과는 다시 시각 승인해야 한다.

| 발표에서 하는 일 | 확인할 구현 | 이 형태를 선택한 이유 | 새 주제에 적용할 때 |
|---|---|---|---|
| 시작 1초에 이미지와 주장을 함께 제시 | `examples/city-guide/src/scenes/01-hero/`, `src/story-runtime.js` | 저녁으로 변하는 도시 이미지가 시간과 장소를 설명하는 동안 주장이 계속 읽힌다. | 새 주제에 맞는 이미지 시퀀스와 정지 포스터를 준비한다. 생성 장면을 실제 사건의 기록처럼 제시하지 않는다. |
| 하나의 동선을 따라 장소를 누적 | `examples/city-guide/src/scenes/02-route/`, `src/story-runtime.js` | 정거장마다 사진과 경로 정보가 함께 변해 설명을 다시 시작할 필요가 없다. | 지명·순서·거리·시간의 근거를 확인한다. 개념 경로라면 그 상태를 표시한다. |
| 정확한 값의 분포를 공개 | `examples/client-proposal/src/scenes/03-evidence/` | 여섯 막대의 높이가 동일한 영점에서 값에 비례하고, 피크 시각과 8.4분 중앙값을 별개 측정으로 구분한다. | 값·단위·기간·분모·출처·실측/합성 여부를 같은 화면에 둔다. 값이 바뀌면 도형과 라벨을 함께 재계산한다. |
| 시간에 따른 한 지표의 변화를 비교 | `examples/annual-report/src/story-runtime.js`의 `03-trend` | 네 분기를 같은 척도에 놓고 마지막 증가 폭의 의미를 짧게 해석한다. | 점의 위치·값·증가율·해석을 동일 데이터에서 계산한다. 필요한 축과 기준선을 유지한다. |
| 같은 분모의 두 비율을 비교 | `examples/annual-report/src/story-runtime.js`의 `04-drivers` | 41%와 54%를 비례 길이로 보여 주어 수치의 차이가 장식 없이 읽힌다. | 분모·기간·합성 여부를 표시하고 두 막대에 같은 척도를 쓴다. |
| 한 사람의 상황 변화를 따라가기 | `examples/client-proposal/src/scenes/04-journey/` | 탐색·상담·결제의 서로 다른 이미지 상태가 발표자의 스크롤로 진행되고, 모션 감소 화면에는 모두 놓인다. | 인물·장소의 연속성이 있는 장면을 준비하고 각 상태의 캡션과 발표 화면 크롭을 확인한다. |
| 운영 선택지를 결정 | `examples/client-proposal/src/scenes/08-options/` | 강조 선택지가 다른 선택지와 동일한 기준에 정렬돼 임의의 카드 나열로 보이지 않는다. | 모든 선택지에 같은 비교 기준을 적용하고 검증되지 않은 승자를 암시하지 않는다. |
| 청중이 답할 수 있는 행동으로 마무리 | `examples/annual-report/src/story-runtime.js`의 `10-close` | 세 판단 요소가 안정된 화면에 남아 발표자가 토론을 열 수 있다. | 실제 청중의 결정 또는 질문으로 바꾸고 작동하지 않는 링크·QR을 넣지 않는다. |

매번 코드 수정 전에 `주장 → 관계 → 근거와 상태 → 발표자의 말/행동 → 화면 변화`를 적는다. 1440×900·1920×1080·모바일·모션 감소 상태에서 진입, 발표 정지, 96/99% 퇴장 캡처를 확인한다. 이 표는 **개별 덱에서 완성된 장면 사례**이지, 같은 이름의 템플릿 유형 전체에 대한 생산 승인 표가 아니다.
